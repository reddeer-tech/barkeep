What's New

BarKeep 0.0.7

Performance

  • Much lower idle CPU. The notch island no longer redraws continuously when nothing is changing — background CPU while an activity is showing drops from ~25% of a core to low single digits, and memory use is down about 20%.
  • Leaner background polling: several system checks now run only when they're actually needed.

News

  • A new News tab and live-activity. Define your own topics; BarKeep pulls matching headlines and shows them one at a time in the pill, with an optional scrolling ticker beside the notch. Quiet hours and a "respect Focus" option keep it out of the way, and enabling it no longer floods you with a backlog.

Notch on MacBooks with a display notch

  • The expanded view now lays out below the physical notch instead of running through it, with the tab name and status chrome tucked neatly beside the cutout.
  • Live-activity icons no longer clip on the taller notched pill.

Fixes

  • Release notes now render properly in the updater (they previously showed raw HTML).
  • The Camera permission card now flips to "Granted" the moment you allow access, matching the other cards.
  • Reminders group under their Reminders.app lists; the microphone attribution label fits longer app names; meeting Join/Copy buttons show as soon as a meeting starts.

System

  • Sparkle automatic updates; runs as a quiet menu-bar agent. macOS 13+, Apple Silicon and Intel (universal).
