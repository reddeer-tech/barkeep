What's New

BarKeep 0.0.9

Fixes

  • Location permission now prompts correctly. The optional Location access (for precise weather) was silently suppressed; enabling it now shows the system prompt as expected.
  • Tidier permissions screen. The permission cards are more compact and fit without scrolling.

BarKeep 0.0.8

Custom Macros (text expansion)

  • A new Custom Macros pane. Type a trigger like EST# and BarKeep replaces it with your output — static text, dynamic tokens ({date}, {time}, {datetime}, {uuid}, {clipboard}), a shell script's result, a pick from a list, or a replayed keystroke sequence. Trigger by a typed abbreviation or a global hotkey. Off by default; keystrokes are matched locally only, never stored, and capture pauses in password fields.

Menu bar & notch

  • Reserve space behind the notch (MacBooks with a notch): an optional toggle inserts a notch-width gap so menu-bar icons don't hide under the cutout.
  • Notched-Mac polish: the expanded island now lays out fully below the physical notch, status dots clear the cutout, and a click-drag inside the island no longer jumps to the file shelf.

Weather

  • Optional precise location. Grant Location (asked only when you open Weather, and skippable) for weather exactly where you are; otherwise it keeps using approximate IP-based location.

System

  • Runs as a quiet menu-bar agent; universal (Apple Silicon + Intel); auto-updating via Sparkle.
